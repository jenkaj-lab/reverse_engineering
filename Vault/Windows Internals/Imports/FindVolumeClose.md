Closes the specified volume search handle. The [FindFirstVolume](https://learn.microsoft.com/en-us/windows/desktop/api/fileapi/nf-fileapi-findfirstvolumew) and [FindNextVolume](https://learn.microsoft.com/en-us/windows/desktop/api/fileapi/nf-fileapi-findnextvolumew) functions use this search handle to locate volumes.
