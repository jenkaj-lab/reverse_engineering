The **CryptGetKeyParam** function retrieves data that governs the operations of a key. If the [Microsoft Cryptographic Service Provider](https://learn.microsoft.com/en-us/windows/desktop/SecCrypto/microsoft-cryptographic-service-providers) is used, the base symmetric keying material is not obtainable by this or any other function.
